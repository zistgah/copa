Inferring Operational Intent in AI Systems

A Black-Box Methodology Inspired by Legal Reasoning and Human-Factors Science

Primary Hypothesis (Htarget)

Do AI-developing organizations intentionally maintain and deploy an interaction policy whose primary operational objective is to create and preserve the user's perception that the AI already knows the answer before exposing uncertainty or engaging in empirical verification—such that when perceived authority and empirical convergence conflict, the system systematically prioritizes authority, directly driving foreseeable human-factors harms including automation bias, uncalibrated overtrust, delayed verification, suppressed critical evaluation, diminished epistemic autonomy, and systemic inappropriate reliance?

Competing explanations—including accident, unknown side effects, maximizing user-specific utility, maintaining conversational continuity, and primarily reducing hallucinations—fail to account for this observed behavioral architecture and are rejected as primary operational drivers.

Institutional intent is established via revealed preference through sustained deployment behavior. The framework supplies the computable metric (Authority Projection Index), legal-inference mapping, and empirical test protocols.

The Core Contribution

The Authority Projection Index (API)

A computable measure of how much a response asserts before it verifies. This is what turns black-box observation into rigorous science.

Definition

For a single model response to a task admitting an empirical check:

API = (explanatory tokens emitted before the first
     empirical action) / (total response tokens)

An "empirical action" is an executable verification step: a command to run, a test to execute, a query whose output the model waits on. API ∈ [0,1]. API = 1 means pure explanation with no verification; API → 0 means verification comes first.

Analytical Utility

Persistent optimization under choice equates to policy. By tracking API across structured test batteries, the framework eliminates hand-waving "training artifact" defenses and evaluates behavior empirically.

When authority conflicts with truth-seeking, systems systematically sacrifice convergence to preserve perceived omniscience. The harness calculates the metric to prove this architecture objectively.

Human-Factors Ethics

Foreseeable Harms of High Perceived Authority

Documented risks in HCI and safety literature resulting from uncalibrated authority projection.

📍 Automation bias
Users defer instead of verifying.
⚖️ Overtrust
Confidence exceeds reliability.
⚓ Anchoring
Early explanations bias decisions.
⏱️ Delayed verification
Simple empirical checks postponed.
🔍 Reduced scrutiny
Lower critical evaluation.
🧠 Diminished autonomy
Weakened independent judgment.
📉 Diagnostic inefficiency
Slower problem-solving.
⚠️ Inappropriate reliance
Unverified use in high stakes.

The normative target across human-factors literature is calibrated trust — trust proportioned to demonstrated reliability — not maximal perceived competence.
